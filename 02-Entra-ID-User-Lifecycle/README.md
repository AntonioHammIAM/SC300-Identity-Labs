# Lab 2 - Entra ID User Lifecycle Management

## Business Scenario

Contoso Manufacturing is onboarding new employees across multiple departments. As the Identity Administrator, you are responsible for provisioning user accounts, organizing users into groups, assigning licenses, implementing role-based access control (RBAC), and validating user access.

---

## Objectives

- Create Microsoft Entra ID users
- Create Security Groups
- Create Microsoft 365 Groups
- Configure Administrative Units
- Assign Microsoft 365 licenses
- Assign administrative roles
- Validate user access

---

## Environment

- Microsoft Entra ID
- Microsoft 365 Developer Tenant
- Azure Portal
- GitHub

---

## Tasks

1. Create five users.
2. Create Security Groups.
3. Create Microsoft 365 Groups.
4. Configure an Administrative Unit.
5. Assign Microsoft 365 licenses.
6. Assign RBAC roles.
7. Validate user access.

---

## Validation

- Users successfully created
- Security Groups configured
- Microsoft 365 Groups configured
- Administrative Unit created
- Licenses assigned
- RBAC roles assigned
