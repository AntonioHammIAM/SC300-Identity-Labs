# Lab 5 - Microsoft Entra Privileged Identity Management (PIM)

## Objective

Configure Microsoft Entra Privileged Identity Management (PIM) to provide just-in-time privileged access using eligible role assignments, MFA, and activation policies.

## Technologies Used

- Microsoft Entra ID
- Privileged Identity Management (PIM)
- Microsoft Entra Roles
- Role Activation
- Azure Portal

## Skills Demonstrated

- Configure PIM role settings
- Configure activation policies
- Require MFA for privileged activation
- Configure justification requirements
- Assign eligible administrator roles
- Activate privileged roles using Just-in-Time (JIT) access
- Review active role assignments

## Outcome

Successfully configured Microsoft Entra Privileged Identity Management to enforce secure administrative access through eligible role assignments, MFA, and Just-in-Time activation.

- Just-in-Time administration
- Eligible vs Active assignments
- MFA enforcement
