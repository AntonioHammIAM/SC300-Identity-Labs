# Lab 6 - Hybrid Identity with Microsoft Entra Connect

## Objective

Demonstrate hybrid identity concepts by documenting Microsoft Entra Connect synchronization, hybrid identity architecture, and directory synchronization between on-premises Active Directory and Microsoft Entra ID.

## Technologies Used

- Microsoft Entra ID
- Microsoft Entra Connect (Azure AD Connect)
- Active Directory
- Hybrid Identity
- Azure Portal

## Skills Demonstrated

- Hybrid identity planning
- Directory synchronization concepts
- User synchronization
- Password Hash Synchronization
- Pass-through Authentication
- Seamless Single Sign-On
- Hybrid identity architecture
